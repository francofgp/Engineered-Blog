I built a fractal generator with matplotlib. The dragon curve emerges from iteratively folding a strip of paper — formally, you can express it as L = L + R where each iteration appends the previous sequence reversed and inverted.

2 # base case

How to pick

  • A · GitHub neutral — pure black BG, máximo pop del teal, cool undertone. Para devs que aman la estética GitHub.
  • B · Slate — bluer undertone, combines with the teal. Trendier (Linear, Notion, Vercel vibes). Pairs with dracula.
  • C · Material warm — softer dark, easier on long sessions pero el teal pierde fuerza. Body↔surface poco contraste.
  • D · Warm-dark — middle ground. BG #16181c es un toque más cálido y menos stark que A, pero suficientemente oscuro para que el teal pop. Surface step grande para que las cards/code blocks se separen del body. Texto cream #e6e4e0 en vez de blanco puro, baja la halation. Pairs con dracula (acentos pink/green warm).

Tip: reducí el zoom del browser, alejate del monitor, leé el párrafo y el código de cada panel. La que se lea más "tuya" gana. Si querés que tunee D más warm/más cool/más dark/teal más verde, decime.
